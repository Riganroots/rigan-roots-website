# Rigan website image guide

Images are grouped by purpose so future updates do not require searching through page code:

- `regions/` — destinations and landscapes
- `adventures/` — activity photos
- `experiences/` — food, farming, people, and village life
- `culture/` — festivals, rituals, and heritage
- `treks/` — named trekking routes and base camps
- `signature/` — Rigan signature packages and special campaigns
- `wellness/` — yoga, meditation, and digital-detox experiences
- `review/` — uploaded images that need identification or correction before use

## Easiest way to replace a picture

Replace the existing file with a new image using the **same folder and filename**. The website link will continue working without any code change.

Examples:

- Replace `regions/pokhara.jpg` to update Pokhara everywhere it is currently linked.
- Replace `adventures/paragliding-pokhara-wide.jpg` to update the paragliding experience card.
- Replace `experiences/momo.jpg` to update the momo image.

Keep photos under 1600 px on the longest side and use JPG quality around 80–85 for good mobile performance.

The file in `review/` named `canyoning-filename-mismatch.jpg` shows a fisherman rather than canyoning, so it is intentionally not used on the live website.
